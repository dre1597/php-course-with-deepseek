# Curso de PHP — Do Zero ao Avançado (Agosto 2026)

Curso completo de PHP puro (sem frameworks), cobrindo desde fundamentos até conceitos
avançados, com foco em **PHP 8.5** (lançado em novembro de 2025) e **PHP 8.4** (LTS ainda mantido).

## Como usar este curso

Cada módulo é autocontido: teoria, exemplos comentados, referências à documentação
oficial e artigos. Ao final de cada módulo há exercícios. Os mini projetos integram
múltiplos conceitos.

**Pré-requisito:** conhecimento básico de HTML (não precisa ser expert).

## Recursos recomendados

- [Documentação oficial do PHP](https://www.php.net/manual/pt_BR/) — referência definitiva
- [PHP: The Right Way](https://phptherightway.com/) — boas práticas sempre atualizadas
- [PHP FIG Standards (PSRs)](https://www.php-fig.org/psr/) — padrões da comunidade
- [PHP 8.5 Release Notes](https://www.php.net/releases/8.5/pt_BR.php) — novidades da versão mais recente
- [PHP 8.4 Release Notes](https://www.php.net/releases/8.4/pt_BR.php) — versão anterior ainda mantida
- [PHP Watch](https://php.watch/) — acompanhamento de mudanças entre versões
- [Laracasts](https://laracasts.com/) — tutoriais em vídeo (PHP + Laravel)
- [PHP Internals News](https://phpinternals.news/) — podcast sobre o desenvolvimento do PHP
